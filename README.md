# 2026 九合一縣市長預測

2026 年 11 月 28 日台灣地方選舉 22 縣市長的每週預測。每期會預測各縣市的投票率、藍白營與綠營候選人的得票數、得票率、催票率、勝率與選情分級，並保留歷次預測，選後與開票結果對照。

- **線上瀏覽**：開啟 GitHub Pages 後，網址為 `https://moonmoonsheep.github.io/taiwan-2026-election-forecast/`（設定方式見下方）
- **更新頻率**：每週一早上新增一期，發布後凍結、不回頭修改

## 名詞

- **得票率**：得票數 ÷ 有效票數
- **催票率**：得票數 ÷ 選舉人數
- **陣營**：藍白營含國民黨、民眾黨，以及兩黨正式推薦或支持的無黨籍；席次另拆藍營與白營（白營：張啓楷、高虹安）。其他無黨籍列為「其他」。
- **選情分級**：依領先者勝率，穩（90% 以上）、傾向（75%–90%）、微幅（60%–75%）、拉鋸（60% 以下）

## 預測方法

1. **結構基本盤**：2022 縣市長 40%、2024 總統 30%、2024 區域立委 30%。民眾黨選票以 75% 轉給藍白、25% 計入綠營；台北 2022 不把黃珊珊算入藍白；嘉義市 2022（延後重選）不列入。
2. **民調整合**：採計近 12 週民調（無近期民調的縣市回溯 32 週），半衰期 14 天，乘樣本數平方根。機構權重：戴立安（信民協會、其在職期間的美麗島電子報）×1.5、震傳媒／山水 ×1.2、其他 ×0.7；TVBS 只採封關民調。未表態依該民調已表態比例分配，並修正機構偏差（判斷值，需驗證）。
3. **混合**：民調充足的縣市民調占 80%、較少 60%、幾乎沒有 30%。
4. **環境修正**：風向由「民調減結構盤」推得，上限北北基桃與五都 ±7.5、其餘 ±5；近 12 週無民調的縣市改用外溢 +2.5。現任 +1.5；滿意度、輿論（含兩黨內部評估）各 ±1.5 以內；黨內分裂個別評估。
5. **不確定性**：蒙地卡羅模擬 20,000 次，含全國共同誤差與縣市誤差。
6. **投票率**：以 2022 投票率為基準，加全國動員與競爭程度調整。

完整說明與修正紀錄見網頁「預測方法」分頁。

## 資料來源

- 歷屆選舉：中選會（經 VoteTW、政大選舉研究中心彙整）
- 民調：維基百科「2026年中華民國直轄市長及縣市長選舉民意調查」與各媒體報導，每筆民調附來源連結
- 人口：內政部戶政司戶口統計速報
